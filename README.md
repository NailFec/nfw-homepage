# nfw-homepage

Personal homepage of **NailFecWebsite**, live at [nailfec.com](https://nailfec.com). This page currently serves as an introduction to me (NailFec).

This is the **third version** of the homepage. In the future, this page will be moved to `nailfec.com/about-me/`, and the main homepage will focus more on the website itself rather than on a personal introduction.

### Design & Implementation

- Built as a front-end only project, since its main purpose is self-introduction.
- Implemented with pure HTML, CSS, and JavaScript, without any framework, to keep the homepage fast and highly compatible across browsers and devices.
- Design principles: simple, animated, and based on the blue color theme.
